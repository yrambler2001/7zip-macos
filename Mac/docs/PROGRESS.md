# 7-Zip for macOS — master feature checklist

Derived from `01-fm-feature-inventory.md` (cited as `01 §x`), `01b-fm-dialogs-settings.md` (`01b §x`) and `03-shell-integration-inventory.md` (`03 §x`). Every checkbox is one Windows 7zFM / 7zG / shell-extension behaviour the port must reproduce; the reference in parentheses names the inventory section that specifies it. Locked decisions and the per-scope deliverables are in `00-orchestration.md`; target layout in `architecture.md`.

Rules for implementation agents:

* Tick a box (`- [x]`) only after the behaviour is built **and** verified in the running app or by a test; mention the verification in `reports/<scope>.md`.
* A box that is deliberately implemented differently from Windows stays unticked and gets a one-line note in the report; the orchestrator moves it to the final section if the deviation is accepted.
* Never rename or renumber a line; add new lines at the end of the scope if the inventories were incomplete.
* Windows resource IDs quoted here (`IDM_*`, `IDD_*`, `IDC_*`, `IDS_*`) must appear as comments next to the code that implements them.
